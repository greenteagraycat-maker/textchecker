# Manhwa Translation Alignment Checker

เว็บแอปสำหรับ Typesetter Manhwa เพื่อตรวจไฟล์แปล `.txt` เทียบกับภาพต้นฉบับ จัดรูปแบบข้อความ และแจ้งจุดที่ควรตรวจสอบ

## คุณสมบัติ
- อัปโหลดภาพหลายไฟล์และเรียงชื่อไฟล์แบบ natural sort
- อัปโหลด TXT ที่มีรูปแบบอังกฤษ 1 บรรทัด ตามด้วยไทย 1 บรรทัด และหัวข้อเลขหน้า เช่น `001`
- แสดงภาพต้นฉบับและรายการข้อความในหน้าเดียวกัน
- แก้ไขคำแปลไทยในตารางได้
- ตรวจบรรทัดคำแปลว่าง, Space/Tab ท้ายบรรทัด, Tab ภายในข้อความ และคำแปลยาวที่อาจมีหลายประโยค
- OCR ภาษาอังกฤษผ่าน Tesseract.js ในเบราว์เซอร์
- แยกรายการด้วยตนเอง, ทำเครื่องหมายให้ตรวจ, ลบรายการ
- ส่งออก TXT พร้อมตัวเลือกคงภาษาอังกฤษ/หัวข้อหน้า/บรรทัดว่าง
- คัดลอกรายงานตรวจสอบ

## ข้อจำกัดสำคัญ
รุ่นนี้เป็น client-side starter ที่เหมาะกับ GitHub Pages และยังไม่ใช่ระบบจับคู่ OCR กับคำแปลแบบสมบูรณ์อัตโนมัติ OCR ใช้แสดงข้อความที่อ่านได้จากภาพเท่านั้น การตรวจจำนวนกล่องข้อความและการจับคู่ EN/TH ต้องยืนยันด้วยสายตา โดยเฉพาะ SFX, ข้อความตกแต่ง, กล่องที่มีหลายประโยค และ OCR ที่อ่านผิด ระบบไม่ส่งภาพหรือ TXT ไปยัง backend ของโปรเจกต์ แต่ไลบรารี OCR โหลดจาก CDN เมื่อใช้งาน

## วิธีใช้บนเครื่อง
1. แตกไฟล์ ZIP
2. เปิด `index.html` ในเบราว์เซอร์สมัยใหม่ หรือใช้ VS Code + Live Server เพื่อความเข้ากันได้ที่ดีกว่า
3. อัปโหลดภาพต้นฉบับ และ TXT
4. ตรวจรายการ แก้ไขข้อความไทย แล้วกด **ส่งออก TXT**

> หาก OCR ไม่เริ่มทำงานเมื่อเปิด `index.html` โดยตรง ให้เปิดผ่าน local web server หรือ GitHub Pages และตรวจว่าเชื่อมต่ออินเทอร์เน็ตได้

## Deploy ไป GitHub Pages
1. สร้าง repository ใหม่ใน GitHub เช่น `manhwa-alignment-checker`
2. อัปโหลด `index.html`, `style.css`, `app.js`, `README.md` ไว้ที่ root ของ repository
3. ไปที่ **Settings → Pages**
4. ที่ **Build and deployment** เลือก **Deploy from a branch**
5. เลือก branch `main` และ folder `/(root)` แล้วกด Save
6. รอ GitHub สร้างเว็บไซต์ แล้วเปิด URL ที่แสดงในหน้า Pages

## ความเป็นส่วนตัว
ไฟล์ภาพและ TXT ถูกอ่านและประมวลผลในเบราว์เซอร์ของผู้ใช้ ไม่ได้ถูกส่งไปเก็บในเซิร์ฟเวอร์ของแอปนี้ อย่างไรก็ตาม OCR ใช้ไลบรารี Tesseract.js จาก CDN และต้องโหลดโค้ดจากผู้ให้บริการภายนอก หากต้องการทำงานออฟไลน์อย่างสมบูรณ์ ควรโฮสต์ไลบรารีและไฟล์ภาษา OCR ไว้ใน repository เอง
